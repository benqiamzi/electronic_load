# 第三阶段架构

第三阶段以第二阶段 M7 基线 `20c9a6d` 为输入，在原有电子负载窗口内增加 USB PD 工作区。电子负载继续通过原有控制器查询设备和更新图表。DRPD 和文件回放各有独立生命周期，选中的工作区只决定显示内容。

| 层 | 组件 | 职责 |
| --- | --- | --- |
| 界面 | `MainWindow`、`WorkspaceSelector`、`UsbPdWorkspace` | 顶部切换、原电子负载页、USB PD 左侧导航、独立连接状态和全局提示。 |
| 界面模型 | `CaptureTableModel`、`CaptureFilter`、`PacketDetails` | 批量接收有序记录、筛选显示窗口、构造选中记录的协议树与字节视图。 |
| 服务 | `WorkspaceManager`、`DeviceService` | 保存界面偏好、提供端口枚举、协调 DRPD 线程及状态信号。 |
| 服务 | `CaptureService`、`ReplayService`、`ExportService` | 启停并归档捕获、按文件顺序回放、按快照导出。 |
| 分析 | `AnalysisService` | 每条流持有自己的 PD 会话、VDM 会话和扩展消息重组上下文，提供统一的记录与诊断。 |
| 协议 | `protocol`、`devices/drpd` | 复用第二阶段解析与第一阶段 CDC/SCPI、二进制块和捕获记录实现。 |

## 线程和数据所有权

- Qt 主线程负责工作区、数据模型和原电子负载控制器。实时与离线使用各自的模型和所选帧，共用过滤条件。
- 每个窗口只创建一个 DRPD 线程。接收的记录先写入临时捕获文件，再批量发给界面。界面确认上一批后继续轮询，等待时显示积压状态。停止时回读设备开关并排空队列。
- 回放线程持有文件流和回放计时器，文件切换或从头播放时重建会话。导出也在文件线程执行，播放中的回放暂停至导出结束。导出分析使用独立会话。
- 表格显示窗口最多保留 4,000 条，另外使用 16 MiB 估算上限约束捕获载荷和跨帧关联数据。旧行滚出时显示累计条数。归档文件保留滚出的记录，导出范围与界面筛选无关。
- 导出通过同目录临时文件和原子替换完成。关闭窗口时，等待捕获停机、串口关闭和文件任务结束后清理临时捕获文件。

## 数据边界

在实时捕获重新开始时重置分析上下文并向归档写入会话边界。同一归档可以保存多个捕获会话，顺序回放和导出在边界同步重置上下文。设备报告的 EPR 配置、捕获观察到的 EPR Source Capabilities 和当前有效 EPR PDO 数量分别显示。文件导入保留样本来源，解析状态独立呈现。
