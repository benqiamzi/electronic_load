# 第三阶段界面要求

进入应用后可以从顶部左侧切换工作区。顶部搜索在 USB PD 工作区筛选报文，通知显示后台任务结果，设置保存界面偏好。状态栏始终显示两个设备的状态。键盘可用 Tab 焦点移动操作，连接失败和文件读写失败通过文字反馈。

| 页面 | 用户操作与显示内容 | 数据来源 |
| --- | --- | --- |
| 电子负载 | 原有测量卡片、图表、手动控制、保护、DAC、CSV 和通信日志。 | 现有电子负载控制器。 |
| 设备连接 | 刷新和选择串口、连接、断开、刷新设备状态。显示身份、固件版本、周期、Sink 状态、EPR 配置和设备缓存计数。 | `DeviceService` / `DeviceState`。 |
| 实时捕获 | 开始、停止、查询源能力、跟随最新记录、清空显示、清空本次捕获、保存和导出。显示总接收数、主机 CRC 错误、诊断数、队列与峰值。 | `CaptureService`、实时模型和归档快照。 |
| 协议分析 | 查看 SOP、Header、消息类型、数据对象、CRC、已解码字节、捕获载荷、时间戳与脉宽。 | 选中记录的 `AnalysisEvent`。 |
| PDO/RDO | 展开源能力、PDO 类型和值以及 RDO 引用、工作点和关联状态。 | PD 会话的消息结果与能力上下文。 |
| VDM/VDO | 查看 VDM Header、SVID、命令、VDO、发现子流程和关联诊断。 | VDM 会话结果。 |
| Extended/EPR | 查看扩展 Header、分块、重组状态、EPR Source Capabilities 以及 EPR 请求上下文。 | 扩展消息重组结果与 PD 会话。 |
| 诊断 | 按严重级别筛选、定位行并查看解析代码、字段层级和原始报文。 | 选中源的分析结果。 |
| 离线回放 | 打开、播放、暂停、停止、逐帧和倍速，显示进度、文件和样本信息。 | `CaptureReader`、`ReplayService`、独立的离线模型。 |

表格提供帧号、时间、SOP、发送端、版本、类型、ID、CRC、状态、来源与摘要。通用过滤包含 SOP、类型、CRC、状态、协议分类、诊断级别和时间范围。关键字对显示字段、十六进制、SVID 和诊断代码生效。部分解析、缺少上下文、未知、语义未支持、无效及 CRC 不可用用文字标识。

实时采集的“清空显示”保留原始归档。“清空本次捕获”须先停止采集并确认，删除会话临时数据。回放文件可以继续播放或从头重放，重新打开文件会清理旧会话。显示窗口滑动后，可以保存归档并离线回看更早的数据。
