# M7 性能与内存验收报告

2026-11-26 在同一台 Windows 11 x64 主机、Intel Core i5-1340P、Python 3.13.2 环境下复测。性能程序使用 `python -S`，与普通单元测试和完整压力测试分开运行。M6 与 M7 的基准每轮均为 4,000 次 260 B 重组、76,000 帧，含数据块和反向请求，交替使用 SOP、SOP′。计时涵盖单帧解析、CRC、载荷校验和重组，预生成向量与串口读取在计时区间外。 [基线与执行命令](M7_BASELINE.md) · [原始测量数据](M7_PERFORMANCE_RESULTS.json)

第 3 轮吞吐比单轮建议值低约 1.1%。三轮合计和中位轮均处于验收范围。M7 的协议修复位于 VDM 分页，等价基准走的 Extended 解析和重组模块沿用 M6 代码。本次记录保留三轮原值，单轮波动原因未单独归因。

启用 `tracemalloc` 的独立运行中，7,600 帧与 76,000 帧的峰值均为 29,769 B。重组器峰值来源字节计数均为 468 B。来源字节计数覆盖合成记录的原始/解码数据与脉宽存储口径，`tracemalloc` 记录 Python 跟踪分配。计时表使用未开启跟踪的运行。
